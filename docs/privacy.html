Política de privacidad de AEROFACTUM

Última actualización: 12 de noviembre de 2026

1. Identificación de la aplicación

AEROFACTUM es una aplicación de automatización de contenido educativo aeronáutico.

Su función es generar y publicar videos sobre conocimientos técnicos, operacionales, financieros y científicos de la industria aeronáutica.

La aplicación integra YouTube Data API v3 mediante OAuth 2.0 para publicar contenido en canales expresamente autorizados.

Canal principal: @aerofactum .

Contacto de privacidad: ari.cesped@gmail.com .

2. Datos a los que accedemos

AEROFACTUM utiliza los permisos concedidos explícitamente por el administrador del canal mediante el sistema OAuth de Google.

Dependiendo del permiso autorizado y de las operaciones realizadas, la aplicación puede acceder a:

  • Identificador, nombre e información básica del canal de YouTube autorizado.
  • Identificadores y metadatos de videos publicados mediante la aplicación.
  • Información necesaria para comprobar que el canal autorizado es el correcto.
  • Tokens de autorización OAuth necesarios para realizar las operaciones permitidas.
  • Respuestas técnicas de YouTube Data API relacionadas con las publicaciones.

AEROFACTUM no necesita conocer ni almacenar la contraseña de la cuenta de Google. La autenticación se realiza mediante OAuth 2.0.

3. Permisos y finalidad del acceso

La aplicación utiliza YouTube API Services. Su integración actual solicita el permiso https://www.googleapis.com/auth/youtube.force-ssl .

El acceso autorizado se utiliza para:

  • Identificar y verificar el canal de destino.
  • Subir videos educativos aeronáuticos.
  • Establecer títulos, descripciones, etiquetas y opciones de visibilidad.
  • Configurar miniaturas personalizadas.
  • Incorporar pistas de subtítulos.
  • Registrar identificadores de publicación y evitar cargas duplicadas.

El permiso solicitado por Google puede autorizar operaciones más amplias que las funciones actualmente utilizadas por AEROFACTUM. La aplicación solo debe realizar operaciones previstas en su código y autorizadas por el administrador del canal.

4. Uso de la información

La información obtenida mediante Google y YouTube se utiliza exclusivamente para operar, autenticar y supervisar las funciones de publicación autorizadas de AEROFACTUM.

La aplicación no utiliza los datos del canal para publicidad personalizada, elaboración de perfiles comerciales ni venta de información.

Los datos de autorización no se utilizan para generar visualizaciones, suscripciones, comentarios o interacciones artificiales.

5. Almacenamiento y seguridad

La automatización se ejecuta mediante GitHub Actions. Las credenciales OAuth se configuran como secretos del repositorio y son utilizadas durante los procesos autorizados.

No deben incorporarse Client Secrets, Refresh Tokens ni contraseñas directamente al código fuente público.

AEROFACTUM puede guardar registros técnicos de producción y publicación, como identificadores de episodios, estados de procesamiento e identificadores de videos de YouTube.

El historial de publicación se conserva en el repositorio configurado para el proyecto. Si el repositorio es público, los registros publicados allí pueden ser visibles para cualquier visitante.

Los archivos audiovisuales temporales y los registros de ejecución pueden almacenarse durante el procesamiento en la infraestructura utilizada por GitHub Actions, de acuerdo con la configuración y las políticas de retención de GitHub.

Se aplican las medidas de seguridad disponibles en los servicios utilizados, sin garantizar que ningún sistema informático esté exento de riesgos.

6. Servicios externos y transferencia de datos

AEROFACTUM utiliza servicios de terceros necesarios para sus funciones:

  • Google y YouTube: autorización OAuth, acceso a YouTube Data API y alojamiento de los videos publicados.
  • GitHub: almacenamiento del proyecto, ejecución de automatizaciones, secretos y registros de trabajo.
  • Wikimedia Commons: consulta y descarga de recursos visuales con licencias abiertas.
  • Servicios de síntesis de voz utilizados por el generador: conversión de texto narrativo a audio.

La información técnica transmitida a cada servicio se limita a la necesaria para realizar la función correspondiente.

Los videos, metadatos y subtítulos enviados a YouTube quedan sujetos también a las políticas de Google y YouTube.

AEROFACTUM no vende a terceros los datos obtenidos mediante la autorización OAuth.

7. Conservación y eliminación de datos

Los tokens OAuth se utilizan mientras exista una autorización válida y sean necesarios para las funciones del proyecto.

Los registros de publicación pueden conservarse para impedir duplicaciones, verificar resultados y diagnosticar errores, hasta que sean eliminados por el administrador.

El administrador puede solicitar la eliminación de registros locales del proyecto y la revocación de las credenciales de acceso.

Los contenidos publicados en YouTube permanecen sujetos a las opciones de gestión y eliminación disponibles en YouTube Studio. Revocar OAuth no elimina automáticamente los videos ya publicados.

Para solicitar información o eliminación de los datos almacenados por el proyecto: ari.cesped@gmail.com .

8. Revocación del acceso a Google

El titular de la cuenta puede retirar su autorización de AEROFACTUM en cualquier momento desde:

Gestionar conexiones y acceso de terceros en la cuenta de Google

Después de revocar el acceso, la aplicación ya no podrá realizar operaciones autorizadas con ese token y podría ser necesario eliminar también los secretos almacenados en GitHub.

9. Cookies y analítica de este sitio

Estas páginas informativas son documentos HTML estáticos. No incluyen un sistema propio de cuentas, formularios de recopilación de datos personales ni herramientas propias de seguimiento publicitario.

Los proveedores de alojamiento y los enlaces a servicios externos pueden procesar información técnica de conexión conforme a sus propias políticas.

10. Privacidad de Google y YouTube

Para conocer cómo Google procesa la información relacionada con sus servicios, consulta:

  • Política de privacidad de Google
  • Términos de servicio de YouTube
  • Políticas de YouTube API Services

11. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones, los servicios integrados o el tratamiento de datos.

Cualquier cambio sustancial en el uso de datos autorizados requerirá las notificaciones o nuevos consentimientos que resulten aplicables.
